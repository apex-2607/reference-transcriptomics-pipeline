# References and Citations

## Core Tools

### Alignment
- Dobin A et al. (2013) STAR: ultrafast universal RNA-seq aligner.
  Bioinformatics, 29(1):15-21.
  https://doi.org/10.1093/bioinformatics/bts635

### Read Counting
- Liao Y, Smyth GK, Shi W. (2014) featureCounts: an efficient general
  purpose program for assigning sequence reads to genomic features.
  Bioinformatics, 30(7):923-930.
  https://doi.org/10.1093/bioinformatics/btt656

### Quality Control
- Andrews S. (2010) FastQC: A quality control tool for high throughput
  sequence data.
  https://www.bioinformatics.babraham.ac.uk/projects/fastqc/

- Bolger AM, Lohse M, Usadel B. (2014) Trimmomatic: a flexible trimmer
  for Illumina sequence data. Bioinformatics, 30(15):2114-2120.
  https://doi.org/10.1093/bioinformatics/btu170

- Ewels P et al. (2016) MultiQC: summarize analysis results for multiple
  tools and samples in a single report.
  Bioinformatics, 32(19):3047-3048.
  https://doi.org/10.1093/bioinformatics/btw354

### Differential Expression
- Love MI, Huber W, Anders S. (2014) Moderated estimation of fold change
  and dispersion for RNA-seq data with DESeq2.
  Genome Biology, 15:550.
  https://doi.org/10.1186/s13059-014-0550-8

- Zhu A, Ibrahim JG, Love MI. (2019) Heavy-tailed prior distributions
  for sequence count data (apeglm).
  Bioinformatics, 35(12):2084-2092.
  https://doi.org/10.1093/bioinformatics/bty895

### Functional Enrichment
- Yu G et al. (2012) clusterProfiler: an R Package for Comparing
  Biological Themes Among Gene Clusters.
  OMICS, 16(5):284-287.
  https://doi.org/10.1089/omi.2011.0118

### Visualization
- Gu Z et al. (2016) Complex heatmaps reveal patterns and correlations
  in multidimensional genomic data. Bioinformatics, 32(18):2847-2849.
  https://doi.org/10.1093/bioinformatics/btw313

- Wickham H. (2016) ggplot2: Elegant Graphics for Data Analysis.
  Springer-Verlag New York. https://ggplot2.tidyverse.org

### Python
- Muzellec B et al. (2022) PyDESeq2: a python package for bulk RNA-seq
  differential expression analysis.
  Bioinformatics, 39(9).
  https://doi.org/10.1093/bioinformatics/btad547
